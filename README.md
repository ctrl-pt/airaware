# AirAware

**Find a better window for time outside.** AirAware turns a simple hourly AQI sample into a glanceable day planner with activity and sensitivity preferences.

## Try it

Open `index.html` in a modern browser. Choose a demo area, activity, and planning preference to update the sample chart and suggestion. No account, install, or API key is needed.

## The demo

- Hourly sample AQI chart for three fictionalized demo areas
- A best-window suggestion that responds to the selected activity
- Clear sample-data labeling and plain-language health caveats
- Responsive, self-contained page

## Scope and limitations

Every reading is illustrative sample data. The prototype has no location access, sensor, live forecast, or medical functionality. Use local air quality authorities for current readings and alerts; the suggestion is not health advice.
